POSITIONING一页看懂

01我们不做「线上展馆」，做一次可被验证的叙事

同类作品普遍「重技术轻叙事」：全景漫游很沉浸，但信息密度低、记不住。我们反着来——轻量交互，强叙事，重点场景做三维，其余用 CSS 与 SVG 解决。

一句话定位：一座可以「摸牌」的线上麻将陈列馆——用一副牌的诞生，讲一座港口城市如何影响了世界的娱乐方式。

为什么是麻将：文化唯一性（国内唯一麻将专题馆）、叙事完整度（起源—定型—传播三段式）、素材丰度（竹骨象牙玉石、筒索万图形、朱红墨绿象牙白）、交互契合度（牌面即按钮，牌墙即列表）。这四点让它比一个「虚拟车展」更适合做成可交互的东西。

为什么是现在这套做法：七个页面全部是原生 HTML/CSS/JS，没有构建工具、没有 CDN、没有网络请求。这意味着两件事：今晚可以直接双击打开演示；三周内五个人可以并行开发而不互相阻塞。

与参赛项目的接口：「几何—数据—行为」三层孪生在这里各有一个落点——牌墙与材质负责几何与材质表现，三级索引负责数据孪生，牌面解码与我的牌面负责行为交互，数据看板把三者串成闭环。

几何层
看得见牌墙 144 张、竹骨材质分层、祠堂空间的光影调性。对应任务清单第二阶段：1:1 重建与材质还原。
数据层
查得到场景—书柜—书册三级编号与坐标绑定，点选调档、档案反查。对应第三阶段新增的三项核心任务。
行为层
玩得动翻牌、解码、拖动材质、点航线、生成牌面卡。每一个动作都埋点，都进看板。
闭环
越用越准互动 → 沉淀 → 洞察 → 改内容。看板上的热度与转化，就是下一轮内容调整的依据。
